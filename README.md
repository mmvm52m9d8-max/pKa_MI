# pKa_MI

量子化学計算と機械学習を用いたフェノール類縁体のpKa予測

ー概要ー
卒業研究の一環として、マテリアルズ・インフォマティクス(MI)の手法を用いて、物質の構造から酸解離定数（pKa)を予測する
回帰モデルを構築しました。

・量子化学計算：ORCA
・機械学習・データ処理：Python


ー手法ー
１．フェノール類縁体18種類の構造最適化計算を実行。
２．計算結果から特徴量として酸素原子の電荷とO-H結合距離を抽出。
３．目的変数を文献値の実験値pKaとし、重回帰分析を実施。


ー結果ー
構築した重回帰分析モデルにより、以下の結果が得られた。

決定係数(R^2) : 0.999
二乗平均平方根誤差(RMSE)：0.070

図の通り、予測値と実験値は理想線(y=x)上にほぼ完全にプロットされており、極めて高い精度でpKaを予測できることが確認することができました。


ー考察ー
１．特徴量の中で計算値pKaの係数が0.9995と最も１に近い値を示しました。これは、今回の機械学習モデルが量子化学計算による理論値をベースラインとし、
　　O-H結合距離やOの電荷といった微小なパラメータで理論値と実験値の誤差を補正していると解釈することができます。これより、物理化学的根拠に基づく予測ができているといえる。

２. O-H結合距離の係数がマイナスとなっています。（-14.54) これはO-Hの結合距離が長い（結合が弱い）ほど、pKaが小さくなるという化学的なセオリーと完全に一致しており、
　　モデルが化学的に妥当な法則を学習していることが確認できます。


－今後の展望ー
今後は対象となるフェノール類縁体のデータ数を増やし、交差検証を用いて過学習の評価を行う。を行い、モデルの汎化性能を高めていく予定です。
