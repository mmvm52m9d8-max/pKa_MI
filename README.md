# pKa_MI

# 量子化学計算と機械学習を用いたフェノール類縁体のpKa予測

## 概要
卒業研究の一環として、マテリアルズ・インフォマティクス（MI）の手法を用いて、物質の構造から酸解離定数(pKa)を予測する回帰モデルを構築しました。

## 使用技術
* 量子化学計算: ORCA
* 機械学習・データ処理: Python (pandas, scikit-learn, matplotlib)

## 手法
1. フェノール類縁体18種類の構造最適化計算を実行。
2. 計算結果から特徴量として　酸素原子の電荷, O-H結合距離, 計算値pKaを抽出。
3. 目的変数を文献値の実験値pKaとし、scikit-learnを用いて重回帰分析を実施。

## 結果
構築した重回帰分析モデルにより、以下の予測精度が得られました。

決定係数 (R^2): 0.999
二乗平均平方根誤差 (RMSE): 0.070

 図の通り、予測値と実験値は理想線（y=x）上にほぼ完全にプロットされており、極めて高い精度でpKaを予測できることが確認できました。

## 考察
今回の高精度な予測の背景について、出力された各特徴量の回帰係数から以下のことが考察できます。

1. 理論計算と機械学習の融合
   特徴量の中で計算値pKaの係数が0.9995と最も1に近い値を示しました。これは、今回の機械学習モデルが量子化学計算によるによる理論値をベースラインとし、O-H結合距離やOの電荷といった微小なパラメータで理論値と実験値の誤差を補正していると解釈することができます。純粋なデータ駆動型ではなく、物理化学的根拠に基づく予測ができていると言える。

3. 化学的直感との一致
   O-H結合距離の係数がマイナスとなっています。これはO-Hの結合距離が長い（結合が弱い）ほど、pKaが小さくなるという化学的な理論と完全に一致しており、モデルが化学的に妥当な法則を学習していることが確認できます。

## 今後の展望
今後は対象となるフェノール類縁体のデータ数を増やし、交差検証を用いて過学習の評価を行い、モデルの汎化性能を高めていく予定です。さらに多様な特徴量を追加し、より精度の高い予測モデルを目指す。
